# ADR-007：座席产品能力留在 SDK 端口，不伪造 PBX

状态：Accepted。

对标浏览器软电话时，静音、保持、DTMF、盲转、设备选择、质量估计和手动重连属于这条 SDK 已经拥有的信令/媒体边界，可以在 Mock 与 SIP 适配器里真实实现。

座席状态、话后处理、CRM 弹屏和录音不依赖 ACD 或录音服务器。它们是宿主端口：状态由本地通话推导，弹屏把号码交给 CRM，录音钩子只通知开始/停止。没有钩子就不会显示“正在录音”。

咨询转接、会议、队列、回呼和跨主机会话需要 PBX、ACD 或外部存储。本仓库不提供这些功能的假成功路径。多实例目前只提供可选的文件会话/限流存储。
