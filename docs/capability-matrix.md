# 能力矩阵

| 能力                        | Mock       | 浏览器/真实模式                     | 验证                 |
| --------------------------- | ---------- | ----------------------------------- | -------------------- |
| 生命周期与通话状态机        | 完整       | 与传输无关                          | 单测 + 压测          |
| 拨入/拨出与控制             | 可演示     | SipTransport 已实现，单通话         | 契约测试；实网待测   |
| 多会话、超时、转接命令      | 支持       | 取决于服务端协议                    | 单元/契约            |
| 重连、心跳、去重、请求超时  | 可故障注入 | ConnectionManager 已实现            | 单测                 |
| 麦克风、设备、轨道释放      | 可模拟拒绝 | BrowserMediaManager                 | jsdom 契约；真机待测 |
| RTCPeerConnection/ICE/Stats | 未伪造     | SIP.js 管理连接与 ICE；Stats 未提供 | 契约测试；实网待测   |
| React/Vue/iframe            | 示例       | 可接入                              | 类型检查             |

真实模式前置条件：合法 PBX/SIP WSS 地址、后端登录、受限分机、TURN、TLS 和号码路由。当前 SIP 使用认证后获取的分机 digest 密码，TURN 使用短期凭证；长期密钥不能写入仓库或前端构建。真实模式转接尚未开放，信令断开后需手动重新连接。详见 `docs/production.md`。
