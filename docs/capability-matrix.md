# 能力矩阵

| 能力                        | Mock       | 浏览器/真实模式          | 验证                 |
| --------------------------- | ---------- | ------------------------ | -------------------- |
| 生命周期与通话状态机        | 完整       | 与传输无关               | 单测 + 压测          |
| 拨入/拨出与控制             | 可演示     | 需实现 SIP Adapter       | Mock E2E             |
| 多会话、超时、转接命令      | 支持       | 取决于服务端协议         | 单元/契约            |
| 重连、心跳、去重、请求超时  | 可故障注入 | ConnectionManager 已实现 | 单测                 |
| 麦克风、设备、轨道释放      | 可模拟拒绝 | BrowserMediaManager      | jsdom 契约；真机待测 |
| RTCPeerConnection/ICE/Stats | 未伪造     | 待 SIP/WebRTC Adapter    | 未验证               |
| React/Vue/iframe            | 示例       | 可接入                   | 类型检查             |

真实模式前置条件：合法 PBX/SIP WSS 地址、后端短期鉴权、STUN/TURN（生产建议 TURN）、TLS、号码路由、录音/隐私/外呼合规策略。禁止把长期 SIP 密钥放进浏览器仓库。
