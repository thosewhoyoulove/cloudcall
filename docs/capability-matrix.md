# 能力矩阵

| 能力                        | Mock               | 浏览器/真实模式                                        | 验证                 |
| --------------------------- | ------------------ | ------------------------------------------------------ | -------------------- |
| 生命周期与通话状态机        | 完整               | 与传输无关                                             | 单测 + 压测          |
| 拨入/拨出与控制             | 可演示             | SipTransport 已实现，单通话                            | 契约测试；实网待测   |
| 盲转                        | 命令成功后结束会话 | SIP REFER 被接受后结束本通；不表示目标已接听           | 契约测试；实网待测   |
| 录音                        | 宿主钩子           | 同一钩子，不在浏览器采集或存储音频                     | 单测                 |
| 座席状态 / CRM 弹屏         | 客户端状态         | 不依赖 ACD；忙线与话后由 SDK 推导                      | 单测                 |
| 通话质量                    | 可注入档位         | WebRTC inbound-rtp / candidate-pair 估计               | 单测；实网待测       |
| 多会话、超时                | 支持               | 真实模式默认单通话                                     | 单元/契约            |
| 重连、心跳、去重、请求超时  | 可故障注入         | ConnectionManager；媒体 disconnected 进入 reconnecting | 单测                 |
| 麦克风、设备、轨道释放      | 演示设备           | BrowserMediaManager 与 SIP 约束                        | jsdom 契约；真机待测 |
| RTCPeerConnection/ICE/Stats | 未伪造媒体         | SIP.js 管理连接与 ICE；SDK 读取 stats                  | 契约测试；实网待测   |
| React/Vue/iframe            | 示例               | 可接入，含座席状态订阅                                 | 类型检查             |

真实模式前置条件：合法 PBX/SIP WSS 地址、后端登录、受限分机、TURN、TLS 和号码路由。当前 SIP 使用认证后获取的分机 digest 密码，TURN 使用短期凭证；长期密钥不能写入仓库或前端构建。咨询转接、会议、队列和回呼需要 PBX/ACD，当前不实现。信令断开后需手动重新连接。详见 `docs/production.md`。
